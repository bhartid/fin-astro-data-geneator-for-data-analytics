# Feature Catalogue: Western and Vedic Astrology Along a Time Axis

This document lists the features of Western astrology and of Vedic (Indian) astrology that can be placed on a time axis, so each one can be calculated for any moment or period and compared with other time-based data such as price charts in any timeframe.

There are two separate tables, one for Western astrology and one for Vedic astrology, because some Vedic features have no Western equivalent. For the Vedic table, every feature carries its Marathi name beside the English name.

## Rule used to decide include or exclude

A feature is **included** when all three tests are met:

1. It is a recognised technique of Western or Vedic astrology.
2. It is fully determined by astronomical positions, the moment in time and, where needed, an observer's location or a birth or inception chart.
3. It varies along time (as a value, an event or a period), or it is a fixed property of a birth or inception chart (or a fixed lookup) that is read together with time-varying features. For example, a condition such as Mangal Dosha can be present in a chart cast for the start of a company or stock, and can also appear again when the positions at a later moment are measured against that chart.

A feature is **excluded** when it fails one of these tests. Every exclusion is listed in a separate table with its reason.

A feature is not excluded merely because traditional texts first described it for persons. If it can be calculated from positions on a chart of any moment, or on the chart of a company, stock or other instrument, it is included.

Where traditions define the same feature differently (for example the houses counted in Mangal Dosha), each variant is a recognised option of that one feature.

## How to read the tables

**How it appears over time**

| Label | Meaning |
|---|---|
| Value over time | A value that exists at every moment and changes continuously or in steps (for example a planet's longitude, the current tithi) |
| Exact event | Something that happens at an exact moment (for example a planet entering a sign, an eclipse, an exact aspect) |
| Time period | Something that lasts from a start moment to an end moment (for example a dasha, a retrograde stretch, a void-of-course Moon) |
| Fixed reference data | A fixed table or value that does not change with time but is needed to read the other features |

**What it needs** (beyond the date and time itself)

| Label | Meaning |
|---|---|
| Birth or inception chart | The chart of a person, company or instrument at its starting moment, against which later positions are compared |
| Location | The observer's place on Earth (latitude, longitude, altitude) |
| Ayanamsha (sidereal zodiac) choice | The result changes with the ayanamsha chosen, the offset that defines the sidereal zodiac. Features that do not list it give the same result for every ayanamsha |
| KP ayanamsha choice | The same, using the ayanamsha conventional in the Krishnamurti Paddhati system |
| Nothing extra | Only the date and time are needed |
